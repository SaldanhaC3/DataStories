# Dados de exemplo

Tabelas para experimentar o editor. **Todos os números são fictícios**, gerados apenas para
demonstração — não use nenhum deles como fonte.

Cada arquivo usa ponto e vírgula como separador e vírgula como decimal, no formato que sai de uma
planilha configurada em português. O editor detecta os dois automaticamente; estes arquivos servem
justamente para testar essa detecção.

| Arquivo | Serve para |
|---|---|
| `receita-por-canal.csv` | série temporal com duas séries — linha, área |
| `cobertura-por-regiao.csv` | ranking de uma medida — barras horizontais, pirulito, waffle |
| `antes-e-depois.csv` | duas medidas por categoria — haltere, inclinação |
